# Edge OIDC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put Proxmox, TrueNAS, UniFi and PBS behind the cluster's Authentik login on the edge Traefik LXC, so they can be reached from outside. LAN access stays login-free.

**Architecture:** `traefik-oidc-auth` is vendored as a second local plugin, through a shared `install_plugin` function in `apply-edge.sh`. An `oidc-auth` middleware reuses the cluster's `traefik` Authentik application. In `routes.yaml`, `auth: oidc` swaps `lan-only` for `oidc-auth`.

**Tech Stack:** Traefik 3.7 local plugins, traefik-oidc-auth v0.22.0, Authentik, SOPS, bash smoke test.

**Spec:** `docs/superpowers/specs/2026-11-19-edge-oidc-design.md`

## Global Constraints

- Plugin `github.com/sevensolutions/traefik-oidc-auth` at `v0.22.0`, as `TRAEFIK_OIDC_AUTH_VERSION` in `forge/config/edge/versions.env`, annotated `# renovate: datasource=github-releases depName=sevensolutions/traefik-oidc-auth`. It is fetched only by `apply-edge.sh`.
- Provider `https://auth.vaderrp.com/application/o/traefik/`, `CallbackUri: /oidc/callback`, scopes `openid profile email`.
- `BypassAuthenticationRule` is exactly ``HeaderRegexp(`X-Real-Ip`, `^192\.168\.`)``.
- There is no `Authorization`/`AssertClaims` block.
- Secrets go in `forge/secrets.sops.yaml` as `edge_oidc_client_id`, `edge_oidc_client_secret` and `edge_oidc_encryption_secret`, copied from cluster Secret `network/traefik-oidc-secret` (keys `OIDC_CLIENT_ID`, `OIDC_CLIENT_SECRET`, `OIDC_ENCRYPTION_SECRET`). Never print them.
- Commit and push to homeops `main`, with no AI attribution. `bash forge/edge-smoke.sh 192.168.0.5 --wan` (WSL) must be green at the end.

## Review Focus

1. **A non-LAN client must never reach these four UIs without login**, including direct-to-WAN-IP requests with a forged `X-Real-Ip`. warp rewrites it, so smoke `oidc-required-from-vps` covers this.
2. **LAN clients must not be sent to Authentik** (bypass), so smoke `oidc-lan-bypass-*` checks it.
3. **Authentik unreachable at Traefik start** must not take down unrelated routes: the middleware is per-router. Covered by inspection; the reviewer checks it.
4. **Proxmox and PBS consoles** (websockets) must work after login. That is Olli's browser check, listed in the final message.
5. **Plugin install refactor** must not change warp's install marker or patch behaviour. The existing apply harness (guard, certcheck and hook tests) must stay green.
